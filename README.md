## Projects

### [Ride Booking Microservices](https://github.com/Andrew-003/ride-booking-microservices)
`Java 17` `Spring Boot` `Apache Kafka` `Redis` `MySQL` `Docker`

Spring Boot microservices for ride requests, driver matching and the trip lifecycle (request, match, start, complete, cancel). Services communicate asynchronously through Kafka events, with custom event consumers and error handling to keep data consistent. Redis geospatial indexing powers proximity-based driver search, and everything runs locally with Docker Compose.

### [Stripe Payment Integration System](https://github.com/Andrew-003/stripe-payment-integration)
`Java 17` `Spring Boot` `MySQL` `JDBC` `HMAC-SHA256` `SLF4J`

REST APIs for the payment lifecycle using Stripe Checkout, Payment Intents and webhooks. API and webhook validation uses HMAC-SHA256, and transaction state is persisted with a focus on staying consistent through partial failures. Documented with Swagger and configured with Spring Profiles (dev / QA / UAT / prod).

### CorkPOS payment service layer (private repository)
`Node.js` `TypeScript` `Express.js` `Prisma` `PostgreSQL`

As a remote backend volunteer contributor to a US-based startup, I built a centralised service layer that standardises payment integrations across providers (Finix, PayArc). It includes idempotent payment processing to prevent duplicate transactions on retries, webhook handling with deduplication and safe retries, and money stored as integers to avoid floating-point errors.
